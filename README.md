# Agenda de Contactos

Aplicación web para gestionar una agenda personal de contactos.

> Proyecto realizado por Blanca siguiendo la metodología *Learn by doing*.

## Funcionalidades

- Inicio de sesión con username y contraseña.
- Crear, consultar, buscar, actualizar y eliminar contactos.
- Guardar teléfonos, emails y fotos de perfil.
- Mostrar automáticamente el usuario y su rol.
- Reutilizar cabecera, menú y pie de página mediante `includes/`.

## Tecnologías

`PHP 8` · `HTML5` · `CSS3` · `Git` · `GitHub`

## Ejecución rápida

1. Inicia Apache desde WampServer o XAMPP.
2. Abre:

   ```text
   http://localhost/proyectos/agenda/
   ```

3. Usa estas credenciales de prueba:

   ```text
   Username: admin
   Contraseña: 1234
   ```

El usuario `admin` recibe automáticamente el rol **Administrador**.

Para consultar la estructura, el funcionamiento y las decisiones técnicas, visita la [descripción completa del proyecto](readme/01_Descripcion.md).
